# Token Usage Lab - Windows 安装说明

分发版本：v0.1.0-beta.2，公开测试版。应用内部版本仍为 0.1.0，统计逻辑与 beta.1 相同。

## 安装与启动

1. 从本项目 GitHub Releases 下载名称以 `windows-x64-Setup.exe` 结尾的文件。
2. 核对来源和 SHA-256 后双击运行，按安装向导完成安装，不需要先解压。
3. 默认安装到当前用户，不需要主动选择“以管理员身份运行”。不要安装到其他 AI 工具或统计账本目录。
4. 从开始菜单打开 **Token Usage Lab**。中文说明书 `README.md`、许可证和第三方声明保存在安装目录中。

无需安装 Node.js、Rust、Docker，无需注册账号或填写 API Key。安装包适用于 Windows x64，不是 Mac 或 Windows ARM64 版本。

程序需要 Microsoft Edge WebView2 Runtime。安装器在缺少运行时时会联网下载并调用 Microsoft 官方安装程序；没有网络或公司策略阻止安装时，请联系 IT，不要关闭防护或强行提权。已有运行时不会被本安装包主动重装。

## 系统安全提示

本安装包和程序尚未数字签名，可能被 SmartScreen 或公司应用控制策略拦截。请确认发布来源、核对校验值，并按系统允许的单应用确认流程或由 IT 处理。若提示恶意软件、文件损坏、校验不符或公司策略禁止运行，应停止安装。

校验和只用于确认下载完整性，不代替发布者签名。不要关闭杀毒软件，不运行绕过安全策略的脚本。

## 日常使用

首次启动会只读扫描当前用户的默认工具目录；日志较多时请等待采集结束。之后每 60 秒自动刷新，也可使用右上角刷新按钮。退出应用后不继续采集，不自动开机启动。

使用来源、模型和日期筛选查看用量；“未发现目录”或“未覆盖”不代表没有消耗。“部分覆盖”意味着数字不是完整账单。只统计日志中明确报告的 Token，不把积分、文字长度或请求数换算成 Token；参考费用未知，实际账单未接入。

已接入九个本地来源：WorkBuddy、Codex、Claude Code、OpenClaw、Gemini CLI、Pi、OpenCode、新版 Kilo Code、Qwen Code。前三项有 Windows 开发机日志验证，其余六项主要经过合成测试；不承诺覆盖全部工具、版本或调用。自定义目录、其他系统用户、WSL、远程主机及网页端不会自动纳入。

## 更新与卸载

更新前先退出正在运行的旧程序，再运行新安装包。旧版便携 ZIP 与安装版共用当前用户的独立统计账本，不要同时运行两个副本。

从 Windows 的“设置 > 应用 > 已安装的应用”中卸载 Token Usage Lab。卸载程序不会删除其他 AI 工具的配置、日志或共享 WebView2 Runtime；本应用的统计账本也保留：

```text
%LOCALAPPDATA%\TokenUsageLab\token-usage-lab.sqlite3
```

只有明确不再需要历史统计时，才由用户自行决定是否处理该数据目录。不要删除其他工具的数据。暂不提供应用内自动更新，新版本从 GitHub Releases 下载。
